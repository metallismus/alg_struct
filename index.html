Ключове запитання: як перетворити велику задачу на зрозумілу послідовність простих дій?

2. Постановка задачі

Аналіз результатів контрольної роботи

У класі навчається 10 учнів. За результатами контрольної роботи вони отримали такі бали:

8, 10, 7, 12, 6, 9, 11, 5, 10, 8

Потрібно створити програму, яка визначить:

  1. середній бал класу;
  2. найвищий і найнижчий результати;
  3. кількість учнів з оцінками 10–12;
  4. кількість учнів з оцінками нижче 7;
  5. відсоток учнів, які отримали 10–12 балів.
Подумайте: чи варто одразу писати програму? Які дані потрібні? Які обчислення доведеться виконати?

3. Декомпозиція — розбиття на підзадачі

Декомпозиція — це поділ складної задачі на менші частини, кожну з яких легше розв'язати окремо.

Головна задача

Висновок: замість однієї великої проблеми маємо кілька зрозумілих підзадач.

4. Виявлення закономірностей

Тепер шукаємо спільне в діях, які потрібно виконати над кожною оцінкою.

Що потрібно знайти?Яку дію виконуємо?
Суму оцінокДодаємо кожну оцінку до змінної total.
Мінімум і максимумПорівнюємо поточну оцінку з найменшою та найбільшою.
Кількість високих балівПеревіряємо умову mark >= 10 і збільшуємо лічильник.
Кількість низьких балівПеревіряємо умову mark < 7 і збільшуємо лічильник.
Головна закономірність: кожну оцінку потрібно опрацювати однаковим набором дій. Отже, доцільно використати цикл for. За один прохід циклу можна виконувати одразу кілька обчислень.

5. Виділення головного — абстрагування

Абстрагування — це зосередження на важливих для розв'язання даних і відкидання другорядної інформації.

ІнформаціяЧи потрібна?Пояснення

Оцінки учнівТакОсновні вхідні дані.

Отже, достатньо працювати з такими змінними:

  • n — кількість учнів;
  • marks — список оцінок;
  • total — сума оцінок;
  • best, worst — найбільша й найменша оцінки;
  • high, low — лічильники високих і низьких результатів.

6. Побудова алгоритму

  1. Почати виконання.
  2. Задати кількість учнів і список оцінок.
  3. Ініціалізувати суму та лічильники нулями.
  4. Початкові значення мінімуму й максимуму взяти з першої оцінки.
  5. Для кожної оцінки зі списку:
    • додати її до суми;
    • оновити максимум і мінімум за потреби;
    • перевірити, чи оцінка не менша за 10;
    • перевірити, чи оцінка менша за 7.
  6. Обчислити середній бал і відсоток високих результатів.
  7. Вивести результати.
Зверніть увагу: цикл потрібен для повторення дій над усіма оцінками, а розгалуження if — для перевірки умов.

7. Реалізація алгоритму мовою Python

У цьому прикладі оцінки вже записані у список. Пізніше можна змінити програму так, щоб користувач вводив їх самостійно.

n = 10

marks = [8, 10, 7, 12, 6,
         9, 11, 5, 10, 8]

total = 0
best = marks[0]
worst = marks[0]

high = 0
low = 0

for mark in marks:
    total += mark

    if mark > best:
        best = mark

    if mark < worst:
        worst = mark

    if mark >= 10:
        high += 1

    if mark < 7:
        low += 1

average = total / n
percent = high / n * 100

print("Середній бал:", average)
print("Найвища оцінка:", best)
print("Найнижча оцінка:", worst)
print("Високий рівень:", high)
print("Низькі результати:", low)
print("Високий рівень, %:", percent)

Результат виконання

Середній бал8,6
Найвища оцінка12
Найнижча оцінка5
Високий рівень4 учні
Нижче 7 балів2 учні
Високий рівень40%

Перевірка: сума всіх оцінок дорівнює 86, тому середній бал — 86 / 10 = 8,6.

8. Практичне завдання для учнів

Аналіз температури повітря

Метеостанція протягом 7 днів фіксувала середньодобову температуру:

12, 15, 18, 14, 20, 22, 16

Створіть програму, яка визначає:

  1. середню температуру за тиждень;
  2. найвищу та найнижчу температуру;
  3. кількість днів із температурою вище 15 °C;
  4. кількість днів із температурою нижче 15 °C;
  5. кількість днів із температурою рівно 15 °C.
Підказка: використайте список, цикл for, умовні оператори if та лічильники. Спочатку складіть план розв'язання, а вже потім пишіть код.
Показати один із можливих варіантів розв'язку 
temps = [12, 15, 18, 14, 20, 22, 16]

total = 0
highest = temps[0]
lowest = temps[0]

above = 0
below = 0
equal = 0

for t in temps:
    total += t

    if t > highest:
        highest = t

    if t < lowest:
        lowest = t

    if t > 15:
        above += 1
    elif t < 15:
        below += 1
    else:
        equal += 1

print("Середня температура:", total / len(temps))
print("Максимум:", highest)
print("Мінімум:", lowest)
print("Вище 15:", above)
print("Нижче 15:", below)
print("Рівно 15:", equal)
